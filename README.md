# vue-map-demo
## 一、前言

本项目用于记录在实际开发中使用到的一些技巧或者是功能。涉及到的`GIS`前端库包括`OpenLayers`、`Leaflet`、`Cesium`等。

本项目底图采用天地图服务，需要具备天地图的`Key`。将自己的`Key`填写到需要修改[`APP.vue`](src/App.vue)中`mapKey`这个变量即可。

## 二、示例与源码位置

| 示例名   | 位置           |
| -------- | -------------- |
| 地图滤镜 | [OpenLayers](src/components/demos/ol/mapFilter.vue) |
| 地图导出 | [OpenLayers](src/components/demos/ol/exportMap.vue)               |



## 三、如何运行项目

### 初始化
```
npm install
```

### 运行
```
npm run serve
```

### 构建
```
npm run build
```
